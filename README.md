Entry for the [The Robot Apology bounty](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59) on make.fun.

A robot's two-line apology: the first sentence owns one specific mistake,
the second says what it learned and what it will do differently.

## Run

```sh
python3 main.py
```

Writes the two lines to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
